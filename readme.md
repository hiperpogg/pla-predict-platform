ЦИФРОВАЯ ПЛАТФОРМА ПРОГНОЗИРОВАНИЯ ИЗМЕНЕНИЯ ПЛА В АГРЕССИВНЫХ СРЕДАХ

Веб-платформа для анализа потери прочности 3D-печатных деталей из полилактида (PLA) при контакте со спиртом. 

Проект разработан в рамках исследовательской стажировки учеников 9-х и 10-х классов Технолицея им. В. И. Долгих на кафедре Передовой инженерной школы (ПИШ) РТУ МИРЭА.

О ПРОЕКТЕ

Приложение загружает реальные результаты механических испытаний из облачной базы данных PostgreSQL (развернутой на платформе Supabase с помощью database.sql) и строит математическую модель (метод наименьших квадратов). Интерактивный дашборд позволяет рассчитать остаточный запас прочности детали в зависимости от времени ее выдержки в растворителе.

ОНЛАЙН ВЕРСИЯ

Проект развернут на облачном хостинге Render и доступен по ссылке:
https://pla-project.onrender.com

Примечание: из-за ограничений некоторых интернет-провайдеров для доступа к сайту может потребоваться включенный VPN.

СТЕК ТЕХНОЛОГИЙ

- Backend: Node.js, Express
- Database: PostgreSQL (Supabase)
- Frontend: HTML5, Tailwind CSS, Chart.js

ЗАПУСК ПРОЕКТА НА ЛОКАЛЬНОМ КОМПЬЮТЕРЕ

Для запуска вам потребуется установленный Node.js.

1. Скачайте репозиторий на свой компьютер и откройте эту папку в терминале (командной строке).
2. Откройте терминал (командную строку / cmd) и перейдите в скачанную папку с помощью команды:
   cd путь_к_папке

3. Установите необходимые библиотеки командой:
   npm install

4. Запустите локальный сервер:
   node server.js

5. Откройте браузер и перейдите по адресу:
   http://localhost:3000

Сервер автоматически подключится к облачной базе данных, скачает результаты испытаний и отрисует интерфейс.

ГЛАВНЫЙ ВЫВОД ИССЛЕДОВАНИЯ

Анализ данных показал, что спиртовая стерилизация 3D-печатных медицинских изделий из PLA недопустима:
- Через 10 секунд экспозиции деталь теряет около 50% прочности.
- На отметке ~20.7 секунд происходит полное разрушение межслойной адгезии.
